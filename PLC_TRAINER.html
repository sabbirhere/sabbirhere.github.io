How a scan cycle works

A PLC repeats three steps, very fast, forever: read inputs, evaluate the ladder logic top to bottom, write outputs. Press RUN to start scanning, then operate the switches on the right — the ladder lights up to show where power is flowing.

Symbol legend
—| |— Normally OpenConducts when the tag is TRUE
—|/|— Normally ClosedConducts when the tag is FALSE
—( )— CoilOUT / SET / RESET / TON / CTU

Parallel branches = OR. Contacts in one branch = AND.

Coil types

OUT — output follows rung power directly.
SET / RST — latches an output on/off; stays after power is removed.
TON — on-delay timer; done bit goes true after the preset time, resets when power is removed.
CTU — counts rising edges up to a preset; use a RES coil to reset it.
